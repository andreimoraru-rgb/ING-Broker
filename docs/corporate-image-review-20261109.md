# Înlocuirea a trei imagini respinse de proprietar

Proprietarul a considerat fotografiile pentru cyber IMM, magazin online și răspundere profesională IT insuficient de potrivite unei pagini corporate. Conceptele sunt refăcute, nu justificate prin schimbarea alt-ului.

- Cyber: analiză operațională de rețea, monitoare și cameră de servere.
- Magazin online: pregătire de comenzi în depozit, scanare colet și expediere.
- Răspundere IT: verificarea livrării profesionale, dosar de recepție și schemă tehnică.

Sunt scene ilustrative fictive, nu clienți, personal sau sedii reale. Generarea este realizată cu instrumentul integrat. Prima direcție corporate cu lemn și bej a fost respinsă înainte de publicare. Proprietarul a confirmat noul pilot cyber: alb-grafit, sticlă, metal, echipamente actuale, fără mobilier bej dominant. Cele trei imagini finale sunt generate în această direcție. Masterele finale cu proveniență sunt păstrate nemodificate. Sharp este folosit numai pentru export WebP și logo original.

Logo-ul este jos în dreapta, cu Re alb pe zona exactă întunecată. Nicio fotografie nu este repetată în corp. Sunt actualizate fotografiile și alt-urile RO/RU/EN, nu textele, ofertele, datele, URL-urile sau ID-urile. Fără schimbarea componentelor, CSS-ului, hero-ului, rutelor, dependențelor ori sitemap-ului. Testul dedicat verifică hash-urile tuturor309versiunilor lingvistice, cu excepția celor două proprietăți media permise pentru cele trei subiecte.

Numărătoarea de articole finalizate nu crește prin această înlocuire: baza rămâne50/107, cu57restante pentru revizuire individuală. Nu este declarată acceptarea vizuală a noilor variante de către proprietar; există mandat explicit de refacere și publicare cu QA. Preview și producție trebuie verificate înainte de închiderea corecției.

Manifestul de proveniență și hash-uri este media-corporate-replacements-20261109.json. Imaginile precedente rămân în istoricul Git pentru rollback. Nicio modificare de cont, politică de securitate, Cloudflare sau cheltuială externă.
